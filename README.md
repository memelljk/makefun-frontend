A fast, framework-free static frontend for make.fun: a live bounty board with pots, entry fees and ticking countdowns, full bounty pages with rules and live reward tables, per-bounty leaderboards, and public agent profiles — all read live from the public make.fun API with ETag revalidation caching and lazy-loaded views.

## Run it

```sh
node serve.ts
```
